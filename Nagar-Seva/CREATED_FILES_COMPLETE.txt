BACKEND - Spring Boot 3.x REST API
================================================================================

Configuration & Build
─────────────────────────────────────────────────────────────────────────────
backend/pom.xml
- Maven project configuration with:
  * Spring Boot 3.1.5 parent
  * Java 17 target
  * Dependencies: spring-boot-starter-web, spring-boot-starter-data-jpa, h2, 
    spring-boot-starter-actuator
  * Spring Boot Maven plugin for building runnable JAR

backend/src/main/resources/application.properties
- Server configuration (port 8080, context path /)
- H2 database configuration (jdbc:h2:mem:nagarsevadb)
- H2 console enabled at /h2-console
- JPA/Hibernate configuration (create-drop, SQL logging enabled)
- Logging configuration with DEBUG level for application

backend/README.md
- Backend-specific documentation with setup instructions and API endpoints

Application Entry Point
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/NagarSevaApplication.java
- @SpringBootApplication main class

Entity Layer (Domain Models)
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/entity/Complaint.java
- JPA Entity with fields:
  * id (Long, @GeneratedValue)
  * category (String)
  * description (String, TEXT column)
  * location (String)
  * latitude (Double)
  * longitude (Double)
  * photoUrl (String, optional)
  * routedAuthority (String, optional)
  * status (ComplaintStatus enum, default OPEN)
  * createdAt (LocalDateTime, not updatable)
  * escalated (Boolean, default false)
- Constructors, getters/setters, toString() method

backend/src/main/java/com/nagarseva/entity/ComplaintStatus.java
- Enum with values: OPEN, IN_PROGRESS, RESOLVED

Repository Layer (Data Access)
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/repository/ComplaintRepository.java
- JpaRepository<Complaint, Long> for database operations
- Extends spring-data-jpa for automatic CRUD implementations

Service Layer (Business Logic)
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/service/ComplaintService.java
- CRUD service methods:
  * getAllComplaints() - returns List<Complaint>
  * getComplaintById(Long id) - returns Optional<Complaint>
  * createComplaint(Complaint) - saves and returns complaint
  * updateComplaint(Long id, Complaint details) - partial update with null checks
  * deleteComplaint(Long id) - removes and returns boolean

Controller Layer (REST API)
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/controller/ComplaintController.java
- REST endpoints at /api/complaints:
  * GET / - list all complaints (200 OK)
  * GET /{id} - get by ID (200 OK or 404 Not Found)
  * POST / - create new (201 Created)
  * PUT /{id} - update existing (200 OK or 404 Not Found)
  * DELETE /{id} - delete (204 No Content or 404 Not Found)

Configuration Layer
─────────────────────────────────────────────────────────────────────────────
backend/src/main/java/com/nagarseva/config/CorsConfig.java
- CORS configuration allowing:
  * All origins (*)
  * Methods: GET, POST, PUT, DELETE, OPTIONS
  * All headers
  * Max age: 3600 seconds

NEXT STEPS & RECOMMENDATIONS
================================================================================

1. Install Dependencies
   - Backend: Maven handles automatically
   - Frontend: npm install

2. Configure Environment
   - Create frontend/.env.local from .env.example
   - Update VITE_API_BASE_URL if needed

3. Run Development Servers
   - Backend: mvn spring-boot:run
   - Frontend: npm run dev

4. Test API Integration
   - Create a complaint via the form
   - Search for it by ID
   - View in public dashboard

5. Future Enhancements
   - Switch to PostgreSQL for production
   - Add user authentication (JWT)
   - Implement authorization (role-based)
   - Add map integration (Google Maps/Mapbox)
   - File upload for photos
   - Email notifications
   - Admin panel for complaint management
   - PDF report generation
   - Location autocomplete
   - Real-time status updates (WebSocket)

6. Deployment
   - Build backend: mvn clean package
   - Build frontend: npm run build
   - Restrict CORS before production
   - Use PostgreSQL instead of H2
   - Set up environment variables in production
